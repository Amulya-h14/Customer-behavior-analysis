# 🛍️ Customer Shopping Behavior Analysis

## 1. Project Overview

Customer Shopping Behavior Analysis is an end-to-end data analytics project focused on understanding customer purchasing patterns, shopping preferences, and buying behavior.

The project uses Python for data loading, Exploratory Data Analysis (EDA), and data cleaning. SQL is used to perform database queries and extract meaningful business insights. Power BI is used to create an interactive dashboard to visualize customer behavior and purchasing trends.

A detailed analytical report and presentation are also prepared using Gamma AI to communicate the findings and support data-driven business decisions.

**Project Objective:**
To analyze customer shopping behavior, identify purchasing trends, understand customer preferences, and generate actionable insights that can help businesses improve customer engagement and decision-making.

## 2. Dataset

- **Dataset Name:** Customer Shopping Behavior Dataset
- **File Name:** `customer_shopping_behavior.csv`
- **Format:** CSV
- **Description:** The dataset contains customer shopping information used to analyze purchasing patterns, preferences, and spending behavior.
- **Data Processing:** Data inspection, missing value handling, duplicate removal, and data type corrections are performed to improve data quality.

### Prerequisites

- Python 3.x
- Jupyter Notebook
- PostgreSQL or SQL Server
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/your-repository.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Customer-Shopping-Behavior-Analysis
```

### Step 3: Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 4: Run Python Analysis

```bash
jupyter notebook
```

Open the analysis notebook and execute the cells to perform data loading, EDA, and data cleaning.

- Create a database in PostgreSQL / SQL Server.
